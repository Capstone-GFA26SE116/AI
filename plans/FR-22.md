## 1. Bên ngoài — nói chuyện với ai

### API
| Method | Endpoint | Request | Response | Lỗi |
|---|---|---|---|---|
| POST | `/assistant/turn` | `{ "text": str (1–500), "language": "vi"\|"en", "history": [{ "role": "user"\|"assistant", "text": str }] (≤ 6), "selected_id": uuid? }` | 200 `Turn` | 401 · 409 `no_active_plan` · 422 · 429 · 502 |

`POST` vì có body và tốn lượt AI — **endpoint này không ghi dữ liệu nghiệp vụ** (chỉ ghi `AIUsageLog` + trừ lượt).
`selected_id`: Mobile gửi khi user bấm 1 lựa chọn của lượt `clarify` trước (kèm lại câu cũ) → bỏ bước so khớp.

```json
// Turn
{
  "kind": "answer" | "clarify" | "unsupported" | "smalltalk",
  "tool": "today_briefing" | … | null,
  "reply": "Hôm nay bạn có 3 việc trên lịch…",   // để đọc to + hiện chữ, ≤ 60 từ
  "emotion": "neutral" | "happy" | "thinking" | "sad",
  "options": [ { "id": "…", "title": "Landing page — Client A" } ],   // chỉ khi clarify, ≤ 3
  "suggestions": [ "Hôm nay tôi nên làm gì?", "Deadline nào đang gấp?" ]  // khi unsupported / smalltalk "help"
}
```

### Dịch vụ khác
- **Gemini:** `LLMClient.generate_json` có sẵn, schema chọn công cụ, timeout `ASSISTANT_LLM_TIMEOUT_SECONDS` (6), không thử lại.
- **Backend:** dùng lại `BACKEND_BASE_URL` (FR-08b-2), **chỉ GET**, gửi kèm nguyên header `Authorization`, timeout `ASSISTANT_BACKEND_TIMEOUT_SECONDS` (5).

### Database
- Đọc: `Task` chưa Done + `Project` của user (để so khớp tên), `UserSubscription` / `SubscriptionPlan` (quota), những gì use case FR-09/12/18/20 đọc sẵn.
- Ghi: chỉ `AIUsageLog` (`Feature = 'Chat'`, #9) và `AiCallsUsed` (trừ lượt).

## 2. Bên trong — logic

### Code nằm ở đâu
- domain: `assistant_tools.py` (enum, schema tham số, kiểm) · `name_matching.py` (#6, dùng cho task và dự án) ·
  `assistant_text.py` (mẫu câu vi / en từng công cụ, ≤ 60 từ, kiểm tên nội bộ — dùng lại kiểm của FR-12) · `spoken_period.py` (buổi → khoảng giờ theo múi giờ user).
- application: `ports/backend_reader.py` (`calendar`, `current_focus`, `projects`, `project_progress`) · `use_cases/assistant_turn.py`.
- infrastructure: `backend/reader_client.py` (httpx GET, như `document_client.py`) · SQL đọc task chưa Done + dự án (repo mới `assistant_repository.py`).
- api: `routes/assistant.py`, `deps.py`.
- prompt: `prompts/assistant_router_v1.md`.
- config: `ASSISTANT_LLM_TIMEOUT_SECONDS` (6) · `ASSISTANT_BACKEND_TIMEOUT_SECONDS` (5) · `ASSISTANT_HISTORY_MAX_TURNS` (6) ·
  `ASSISTANT_HISTORY_MAX_CHARS` (2000) · `ASSISTANT_TEXT_MAX_CHARS` (500) · `ASSISTANT_MIN_CONFIDENCE` (0.5) ·
  `ASSISTANT_MATCH_MIN_SCORE` (0.8) · `ASSISTANT_MATCH_MIN_GAP` (0.2).

### Luồng `/assistant/turn`
1. Kiểm đầu vào → kiểm quota (chưa trừ).
2. Có `selected_id` → vẫn chạy LLM với câu cũ để biết công cụ, rồi dùng `selected_id` thay bước so khớp (đơn giản, vẫn 1 lượt).
3. Prompt: luật + danh sách công cụ + ví dụ + ngày giờ theo múi giờ user + lịch sử (đã che) + câu (đã che) → `generate_json`.
4. LLM hỏng / sai schema → 502, không trừ. Hợp lệ → trừ 1 lượt + `AIUsageLog`.
5. Chạy công cụ (song song nếu cần 2 nguồn) → `assistant_text` → `Turn`.
6. `emotion`: answer bình thường → `happy`; có deadline nguy hiểm / timer quá giờ → `neutral`; clarify → `thinking`; không tìm thấy / lỗi nguồn → `sad`; unsupported → `neutral`.

### Luật mẫu câu
- Giờ đọc dạng "9 giờ 30", không ISO. Danh sách dài → đọc 3–5 mục đầu + "và còn N việc khác".
- Không có dữ liệu (chưa có lịch, chưa đủ mẫu cho FR-18/20) → câu riêng, không im lặng ("Mình chưa đủ dữ liệu, làm thêm vài việc nhé").
